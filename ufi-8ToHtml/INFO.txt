to run file: 
1. Install NodeJS on command line
2. Place file you want to convert in the same folder as "htmlCode.js"
3. in the terminal, travel to the folder where these files are stored
4. run command=> node htmlCode "file to convert"
5. New file will be created with "-kobo" ammended to the new file
